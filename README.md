# aur-packages

AUR packages maintained by me.

Upstream releases are checked daily by GitHub Actions; verified builds are pushed to the AUR automatically, and anything that fails opens an issue instead of shipping.

## Packages

| Package | Upstream |
|---|---|
| [`pineapple-notepad-bin`](https://aur.archlinux.org/packages/pineapple-notepad-bin) | [BLumia/pineapple-notepad](https://github.com/BLumia/pineapple-notepad) |
| [`genoffice-bin`](https://aur.archlinux.org/packages/genoffice-bin) | [genspark-ai/genoffice](https://github.com/genspark-ai/genoffice) |

## Maintainer setup

`AUR_SSH_KEY`: private SSH key of the AUR account.
